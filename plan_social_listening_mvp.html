📡 Módulo Social Listening MVP

Integración Facebook + Apify para análisis de opinión pública sobre candidatos

Proyecto ALTERNIS Inteligencia Electoral Plataforma de scraping Apify Alcance inicial Facebook (MVP) Duración estimada 3 sprints · ~6 semanas

1. Contexto y Objetivo

💡
Propósito del módulo: Permitir a coordinadores y candidatos entender qué opina el público de una persona en redes sociales, extrayendo posts y comentarios de perfiles de Facebook públicos, y analizando automáticamente el sentimiento y los temas recurrentes. Complementa el Semáforo de Posicionamiento (prensa) con datos de redes sociales.

🎯 Problema que resuelve

Los equipos de campaña carecen de una visión consolidada de la conversación social sobre el candidato. Actualmente deben revisar perfiles manualmente, sin métricas, sin tendencias y sin análisis de tono.

✅ Solución propuesta

Módulo integrado en la app existente: el usuario ingresa la URL del perfil de Facebook del candidato o rival, la app scrapea vía Apify, analiza el texto y devuelve un dashboard de sentimiento + n-gramas + resumen ejecutivo.

📐 Posicionamiento en la arquitectura

Sigue exactamente el mismo patrón del módulo posicionamiento.py (Semáforo de Prensa): API externa → extracción de texto → análisis de tono → n-gramas → respuesta estructurada al frontend.

2. Alcance del MVP — ¿Qué incluye y qué queda fuera?

✅ INCLUIDO en el MVP

  • Scraping de posts públicos de un perfil o página de Facebook
  • Extracción de comentarios de esos posts
  • Análisis de sentimiento por comentario (positivo / neutro / negativo)
  • N-gramas (bigramas y trigramas) más frecuentes en comentarios
  • Resumen ejecutivo generado por LLM (Groq, reutilizando infraestructura existente)
  • Panel de resultados en el frontend con gráfica de sentimiento + nube de n-gramas
  • Exportación PDF del reporte (reutilizando informes.py)
  • Protección del endpoint: solo rol coordinador o admin
  • 1 variable de entorno nueva: APIFY_API_TOKEN

🚫 FUERA del MVP (versiones futuras)

  • Otras redes sociales (Instagram, X/Twitter, TikTok)
  • Scraping de grupos privados o cuentas privadas
  • Monitoreo automático / alertas recurrentes (scheduler)
  • Comparación multi-candidato en Social Listening
  • Segmentación demográfica de comentaristas
  • Detección de bots o cuentas falsas
  • Almacenamiento histórico de análisis pasados (v2)
  • Webhooks de Apify para procesamiento asíncrono pesado

3. Actores de Apify — Selección para el MVP

⚠️
Importante: Los actores de Apify solo pueden scraping de contenido público. Perfiles y páginas con privacidad activada no serán accesibles. Comunicar este límite al usuario final en la UI.
Actor Apify Uso en el MVP ID del Actor Datos que devuelve Costo estimado
Facebook Posts Scraper ✅ PASO 1 — Extraer posts de un perfil/página apify/facebook-posts-scraper Texto del post, fecha, likes, shares, URL del post ~$0.50 USD / 1,000 posts
Facebook Comments Scraper ✅ PASO 2 — Extraer comentarios de cada post apify/facebook-comments-scraper Texto comentario, autor, fecha, likes, respuestas ~$0.50 USD / 1,000 comentarios
Facebook Group & Page Scraper 🔶 Alternativa si perfil es Página (no perfil personal) apify/facebook-group-page-scraper Posts + comentarios en un solo actor ~$1.00 USD / 1,000 items
🔑
Estrategia recomendada para el MVP: Pipeline de 2 pasos encadenados: (1) Posts Scraper para obtener URLs de posts → (2) Comments Scraper para cada URL → análisis del texto de comentarios. Limitar a los 20 posts más recientes y máximo 100 comentarios por post para mantener tiempos de respuesta razonables y costo controlado.

"""Social Listening: scraping de Facebook vía Apify + análisis de sentimiento y n-gramas."""
from __future__ import annotations

import os
from collections import Counter
from typing import Optional
from pydantic import BaseModel, HttpUrl

from apify_client import ApifyClient
from sklearn.feature_extraction.text import CountVectorizer
import spacy  # reutiliza el mismo modelo que posicionamiento.py

# ── CONSTANTES ──────────────────────────────────────────────────────────────
ACTOR_POSTS    = "apify/facebook-posts-scraper"
ACTOR_COMMENTS = "apify/facebook-comments-scraper"
MAX_POSTS      = 20      # Límite MVP: posts más recientes
MAX_COMENTARIOS_POR_POST = 100

# Léxicos reutilizados de posicionamiento.py (extraer a módulo compartido en v2)
POSITIVAS = { "apoya", "avance", "celebra", "logro", "mejora", ... }
NEGATIVAS = { "acusa", "denuncia", "critica", "corrupción", ... }

# ── MODELOS PYDANTIC ─────────────────────────────────────────────────────────
class SolicitudSocial(BaseModel):
    url_perfil: HttpUrl          # URL del perfil/página de Facebook
    max_posts: int = MAX_POSTS
    max_comentarios: int = MAX_COMENTARIOS_POR_POST

class ResultadoSocial(BaseModel):
    url_perfil: str
    posts_analizados: int
    total_comentarios: int
    sentimiento: dict            # {"positivo": %, "neutro": %, "negativo": %}
    ngramas: list[dict]          # [{"texto": "...", "frecuencia": N}, ...]
    resumen: str                 # Resumen ejecutivo del LLM
    error: Optional[str] = None  # Si Apify falló o perfil privado

# ── PIPELINE PRINCIPAL ───────────────────────────────────────────────────────
def analizar_perfil(solicitud: SolicitudSocial) -> ResultadoSocial:
    token = os.environ["APIFY_API_TOKEN"]
    client = ApifyClient(token)

    # PASO 1: Obtener URLs de posts
    post_urls = _obtener_posts(client, str(solicitud.url_perfil), solicitud.max_posts)

    # PASO 2: Obtener comentarios de cada post
    comentarios = _obtener_comentarios(client, post_urls, solicitud.max_comentarios)

    # PASO 3: Análisis de sentimiento comentario a comentario
    sentimiento = _analizar_sentimiento(comentarios)

    # PASO 4: N-gramas del corpus completo
    ngramas = _extraer_ngramas(comentarios, n=2, top_k=20)  # bigramas top 20

    # PASO 5: Resumen ejecutivo con Groq (LLM existente)
    resumen = _generar_resumen(sentimiento, ngramas, str(solicitud.url_perfil))

    return ResultadoSocial(
        url_perfil=str(solicitud.url_perfil),
        posts_analizados=len(post_urls),
        total_comentarios=len(comentarios),
        sentimiento=sentimiento,
        ngramas=ngramas,
        resumen=resumen,
    )

# ── FUNCIONES AUXILIARES (bosquejo) ─────────────────────────────────────────
def _obtener_posts(client, url, max_posts) -> list[str]:
    """Ejecuta facebook-posts-scraper y devuelve lista de URLs de posts."""
    run = client.actor(ACTOR_POSTS).call(run_input={
        "startUrls": [{"url": url}],
        "resultsLimit": max_posts,
    })
    items = client.dataset(run["defaultDatasetId"]).list_items().items
    return [item["url"] for item in items if "url" in item]

def _obtener_comentarios(client, post_urls, max_por_post) -> list[str]:
    """Ejecuta facebook-comments-scraper para cada post y acumula texto."""
    textos = []
    for post_url in post_urls:
        run = client.actor(ACTOR_COMMENTS).call(run_input={
            "postUrls": [post_url],
            "resultsLimit": max_por_post,
        })
        items = client.dataset(run["defaultDatasetId"]).list_items().items
        textos += [item["text"] for item in items if item.get("text")]
    return textos

def _analizar_sentimiento(comentarios: list[str]) -> dict:
    """Clasifica cada comentario y devuelve proporciones."""
    conteo = Counter()
    for texto in comentarios:
        palabras = set(texto.lower().split())
        pos = len(palabras & POSITIVAS)
        neg = len(palabras & NEGATIVAS)
        if pos > neg:   conteo["positivo"] += 1
        elif neg > pos: conteo["negativo"] += 1
        else:           conteo["neutro"] += 1
    total = sum(conteo.values()) or 1
    return {k: round(v / total * 100, 1) for k, v in conteo.items()}

def _extraer_ngramas(comentarios: list[str], n: int, top_k: int) -> list[dict]:
    """Extrae los n-gramas más frecuentes del corpus."""
    corpus = [" ".join(comentarios)]  # concatenar para CountVectorizer
    vec = CountVectorizer(ngram_range=(n, n), stop_words=list(STOP_WORDS_ES))
    X = vec.fit_transform(corpus)
    freqs = zip(vec.get_feature_names_out(), X.toarray()[0])
    top = sorted(freqs, key=lambda x: x[1], reverse=True)[:top_k]
    return [{"texto": t, "frecuencia": int(f)} for t, f in top]

def _generar_resumen(sentimiento, ngramas, url_perfil) -> str:
    """Usa Groq para generar un resumen ejecutivo interpretando los datos."""

from backend import social_listening  # importar al inicio junto a los otros módulos

@app.post("/api/social/analizar")
async def analizar_social(
    solicitud: social_listening.SolicitudSocial,
    usuario=Depends(auth.requiere("coordinador"))
):
    """Ejecuta el pipeline de Social Listening para un perfil de Facebook."""
    try:
        resultado = await asyncio.get_event_loop().run_in_executor(
            None, social_listening.analizar_perfil, solicitud

10. Riesgos y Mitigaciones

RiesgoProbabilidadImpactoMitigación
Perfil de Facebook es privado → sin datos Alta Alto Detectar respuesta vacía de Apify y mostrar mensaje claro al usuario. Documentar la limitación en la UI.
Tiempo de scraping excede 2 minutos → timeout HTTP Media Alto Ejecutar el scraping en run_in_executor (ya contemplado). Para MVP: limitar a 20 posts y 100 comentarios.
Apify cambia los IDs o estructura de los actores Baja Alto Centralizar los IDs de actores en constantes en social_listening.py para cambiarlos en un solo lugar.
Costo de Apify se dispara con uso intensivo Baja Medio Configurar límite de créditos mensual en Apify Console. Mostrar estimación de costo antes de ejecutar el análisis.
Análisis de sentimiento léxico impreciso (modismos políticos mexicanos) Alta Medio Para MVP es aceptable. En v2: análisis por comentario usando Groq para mayor precisión contextual.
Facebook bloquea el scraper de Apify (cambios en HTML) Baja Crítico Es responsabilidad de Apify mantener sus actores. Monitorear el status de los actores. Considerar el Group & Page Scraper como alternativa.

Resumen Ejecutivo

El módulo de Social Listening MVP puede construirse en 6 semanas siguiendo el mismo patrón arquitectónico del Semáforo de Posicionamiento ya existente. La integración con Apify a través de su SDK oficial (apify-client) es directa y bien documentada. El análisis de sentimiento reutiliza la infraestructura SpaCy y los léxicos ya presentes en el proyecto, y el resumen ejecutivo reutiliza la integración con Groq.

El costo operativo de Apify es marginal frente al valor generado ($0.10–$2 USD por análisis vs. $2,490–$18,500 MXN/mes de suscripción). La principal restricción técnica es que solo funciona con perfiles y páginas públicas de Facebook.

La inversión en este módulo diferencia significativamente la plataforma frente a competidores, convirtiendo a ALTERNIS en una herramienta completa de inteligencia electoral: prensa digital (ya existe) + redes sociales (nuevo módulo) + análisis territorial + gestión de campaña.
